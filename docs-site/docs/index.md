# AXEM-SX Documentation

**Your workstation, governed from your workstation.**

AXEM-SX is a sovereignty-focused Linux distribution built on
openSUSE Leap 16.0. This is its documentation.

It is written for two kinds of readers — the operator who wants their
machine to do exactly what they ask, and the curious newcomer who
just installed it and is wondering what's on screen.

## A few things to know

!!! note "This documentation is young"

    AXEM-SX 1.0.1 *(Codename: Gold)* shipped recently. This portal is
    being filled in deliberately, section by section. If a page is
    marked **work in progress**, that is honest — not a placeholder we
    forgot to remove. Pages with content are calm, tested, and as
    accurate as we can make them.

!!! tip "Two languages, English first"

    This documentation is written in **English first** and translated
    to **French** as pages stabilize. If you land on a page that has
    not yet been translated, the English version is shown with a
    discreet banner. To switch language, use the language picker in
    the top bar.

!!! info "Found something wrong?"

    Every page has an **Edit this page** link in its top-right corner.
    It opens the source Markdown on GitHub. Fix the typo, propose a
    clearer sentence, or open an issue. We welcome the contribution.
