# Vous arrivez de...

Vous n'arrivez pas sur une page blanche. Vous arrivez avec des
habitudes, une mémoire musculaire, un vocabulaire et des attentes
forgés ailleurs. C'est une force. Ces guides traduisent ce que vous
savez déjà en termes AXEM-SX — sans prétendre que les différences
soient plus grandes qu'elles ne le sont.

Choisissez la page qui correspond à votre ancien système. Chacune
est courte, riche en tableaux, et honnête sur ce qui change et ce
qui ne change pas.

## Pages de cette section

- **[Vous arrivez d'Ubuntu ou Debian](ubuntu-debian.md)** — apt vers
  zypper, PPA vers OBS, Snap vers Flatpak, Timeshift vers Snapper.
  Le chemin d'arrivée le plus courant.
- **Vous arrivez de Fedora ou RHEL** — *bientôt.* Le saut le plus
  court : même RPM, même systemd, cadence de publication similaire.
  Surtout un changement de vocabulaire.
- **Vous arrivez d'Arch** — *bientôt.* Pour les utilisateurs qui
  veulent la discipline rolling sans la trépidation rolling. Pacman
  vers zypper, AUR vers OBS, cadence plus calme.
- **Vous arrivez de macOS** — *bientôt.* Ponts conceptuels : ce qui
  rappelle la maison dans KDE Plasma, où se trouve le dock, où
  vivent les préférences.
- **Vous arrivez de Windows** — *bientôt.* Ponts conceptuels :
  barre des tâches, menu démarrer, chemins de fichiers, lettres de
  lecteur, panneau de configuration.

!!! note "En cours d'écriture"

    Les pages marquées *bientôt* ne figurent pas encore
    délibérément dans la navigation latérale. Elles y apparaîtront
    une fois écrites. Chaque nouveau guide d'arrivée demande une
    session d'écriture concentrée — nous préférons publier trois
    bons guides plutôt que dix superficiels.
