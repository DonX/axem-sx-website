# Coming From...

You're not arriving on a blank page. You're arriving with habits,
muscle memory, vocabulary, and expectations from somewhere else.
That's a strength. These guides translate what you already know
into AXEM-SX terms — without pretending the differences are larger
than they are.

Pick the page that matches your previous system. Each one is short,
table-heavy, and honest about what changes and what doesn't.

## Pages in this section

- **[Coming from Ubuntu or Debian](ubuntu-debian.md)** — apt to
  zypper, PPAs to OBS, Snap to Flatpak, Timeshift to Snapper. The
  most common arrival path.
- **Coming from Fedora or RHEL** — *coming soon.* The shortest
  jump: same RPM, same systemd, similar release cadence. Mostly a
  vocabulary swap.
- **Coming from Arch** — *coming soon.* For users who want the
  rolling discipline without the rolling churn. Pacman to zypper,
  AUR to OBS, calmer cadence.
- **Coming from macOS** — *coming soon.* Mental-model bridges:
  what feels at home in KDE Plasma, where the dock is, where the
  preferences live.
- **Coming from Windows** — *coming soon.* Mental-model bridges:
  taskbar, start menu, file paths, drive letters, control panel.

!!! note "Work in progress"

    Pages marked *coming soon* are deliberately not yet listed in
    the side navigation. They will appear there when written. Each
    new arrival guide takes one focused writing session — we'd
