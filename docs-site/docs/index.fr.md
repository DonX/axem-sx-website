# Documentation AXEM-SX

**Votre poste de travail, gouverné depuis votre poste de travail.**

AXEM-SX est une distribution Linux **axée sur la souveraineté**,
construite sur openSUSE Leap 16.0. Voici sa documentation.

Elle s'adresse à deux types de lecteurs — l'opérateur qui veut que sa
machine fasse exactement ce qu'il lui demande, et la personne curieuse
qui vient de l'installer et se demande ce qui s'affiche à l'écran.

## Quelques précisions

!!! note "Cette documentation est jeune"

    AXEM-SX 1.0.1 *(Nom de code : Gold)* est sortie récemment. Ce
    portail est rempli délibérément, section par section. Si une page
    est marquée **en cours**, c'est honnête — pas un oubli. Les pages
    publiées sont calmes, testées, et aussi exactes que possible.

!!! tip "Deux langues, l'anglais d'abord"

    Cette documentation est rédigée **d'abord en anglais** puis
    traduite en **français** au fur et à mesure que les pages se
    stabilisent. Si vous arrivez sur une page non encore traduite, la
    version anglaise s'affiche avec une bannière discrète. Pour
    changer de langue, utilisez le sélecteur en haut.

!!! info "Vous avez trouvé une erreur ?"

    Chaque page possède un lien **Modifier cette page** dans son coin
    supérieur droit. Il ouvre le Markdown source sur GitHub. Corrigez
    la coquille, proposez une phrase plus claire, ou ouvrez un ticket.
    Nous accueillons la contribution.
