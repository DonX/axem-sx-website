# Make it Yours

The system you install is a starting point, not a contract. AXEM-SX
ships with a deliberate Wood & Gold posture and a Plasma desktop
arranged the way we'd arrange a fresh workstation. None of that is
permanent. None of it is sacred.

This section is the *appropriation* layer. Every recipe here lets
you reshape the surface — the dock, the panels, the icons, the
fonts, even the entire desktop environment — **without changing the
SUSE motor underneath.** Btrfs, Snapper, zypper, the kernel, the
firewall: untouched. The dress changes. The body stays.

The civic point: nothing here is one-way. Every change is
opt-in, undo-able, and snapshot-protected. Try a layout. Don't like
it. Roll back. Try another. The system encourages experimentation
because it's built to forgive it.
